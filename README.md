## 🚀 Featured Projects

### 📱 ContactRide

A ride-booking application built for the Indian market where users book rides through their phone contacts instead of matching with strangers.

**Highlights**
- React Native / Expo mobile application
- Firebase Authentication and Firestore
- ~19-screen prototype covering onboarding, OTP login, booking, live tracking, payment, and driver dashboard
- Safety-first features including SOS and live location sharing
- Multilingual support: English, Hindi, and Telugu
- Successfully previewed through Expo Go
- Pitched toward T-Hub's RubriX incubation program

| Layer | Technology |
|---|---|
| Mobile | React Native, Expo |
| Backend | Firebase |
| Authentication | Firebase Auth |
| Database | Firestore |
| Languages | JavaScript / TypeScript ecosystem |
